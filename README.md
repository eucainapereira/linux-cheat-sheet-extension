# 🐧 Linux Cheat Sheet Extension

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)
![Platform](https://img.shields.io/badge/platform-Edge%20%7C%20Chrome-orange.svg)

Uma extensão de navegador moderna e ultra-veloz desenvolvida para ser o braço direito de desenvolvedores e administradores de sistema. Tenha acesso instantâneo a mais de **260 comandos Linux** organizados de forma inteligente.

---

## ✨ Funcionalidades Principais

- **🚀 Banco de Dados Robusto**: Mais de 260 comandos divididos em 15 categorias estratégicas (Sistema, Redes, Segurança, Docker, Git, etc).
- **🛠️ Ferramentas Modernas**: Seção exclusiva para alternativas modernas escritas em Rust (`bat`, `eza`, `fd`, `rg`, `btm`).
- **📋 Copiar em um Clique**: Copie qualquer comando instantaneamente para sua área de transferência.
- **🔍 Busca Inteligente**: Filtre comandos e descrições em tempo real com performance de 60fps.
- **🎨 Design Premium**: Interface inspirada em *Glassmorphism* com modo escuro nativo e micro-animações suaves.
- **📦 Offline First**: Funciona totalmente offline, sem dependências externas pesadas.

---

## 📸 Interface

O design foi projetado para ser discreto e eficiente:
- **Sidebar Navegável**: 15 categorias com ícones intuitivos.
- **Grid de Comandos**: Cards responsivos com realce de sintaxe no estilo terminal.
- **Feedback Visual**: Notificações Toast para confirmação de cópia.

## 🚀 Como Instalar (Desenvolvedor)

Como esta é uma extensão em desenvolvimento, siga estes passos para carregar no seu navegador:

1. Faça o download ou clone este repositório:
   ```bash
   git clone https://github.com/eucainapereira/linux-cheat-sheet-extension.git
   ```
2. Abra o Chrome ou Edge e vá para a página de **Extensões** (`edge://extensions` ou `chrome://extensions`).
3. Ative o **Modo do Desenvolvedor** no canto superior direito.
4. Clique em **Carregar descompactada**.
5. Selecione a pasta onde você clonou o projeto.
6. Pronto! A extensão aparecerá na sua barra de ferramentas.
